
# METIS with NVOL

This repository is the work of my master thesis. All of the METIS framework has been taken from https://github.com/KarypisLab/METIS, what is new in this repository is the adaption and changes needed to support NVOL. In order to install and run METIS please go to METIS's own repo and follow the instructions there, with the only difference being that you use this repository instead.

When the installation is complete, you can run gpmetis with the -objtype=nvol parameter which will use NVOL.
